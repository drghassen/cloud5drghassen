# Storage module

Creates a private S3 bucket with public access blocked, bucket-owner enforced
ownership, server-side encryption, versioning, a lifecycle policy, and a
bucket policy that requires TLS.

See `variables.tf` and `outputs.tf` for the module interface, and
`storage.tftest.hcl` for plan-only tests.
